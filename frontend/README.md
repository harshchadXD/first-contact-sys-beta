# First Contact.sys — Frontend Starter

A minimal, zero-dependency starter for the First Contact.sys lunar landing-site exploration interface.

## Prerequisites

- **Node.js**: v18+ (tested on Node v24.19.0)
- **npm**: v9+ (tested on npm 11.17.0)

## Local Development Setup

1. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser at the URL shown in terminal (typically `http://localhost:5173/`).

## Production Build & Preview

- **Build for production:**
  ```bash
  npm run build
  ```
- **Preview production build locally:**
  ```bash
  npm run preview
  ```
